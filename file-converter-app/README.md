# File Converter Pro

Мощное кроссплатформенное приложение для конвертации файлов с графическим интерфейсом.

## Возможности

- ✅ Конвертация DOCX/DOC в PDF
- ✅ Конвертация изображений (PNG, JPG, WEBP, BMP и др.)
- ✅ Пакетная обработка файлов
- ✅ Drag & Drop поддержка
- ✅ Многопоточная конвертация
- ✅ Настройка качества изображений
- ✅ История конвертаций
- ✅ Темная тема
- ✅ Поддержка Windows, macOS, Linux
